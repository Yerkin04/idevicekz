# Исправление раздела «Склад»

## Что изменено

- Ошибки Supabase при добавлении модели или партии теперь отображаются под формой.
- Добавлены сообщения об успешном сохранении.
- Добавлена проверка названия, количества, цены и даты.
- Кнопки показывают состояние «Добавление…» и защищены от повторного нажатия.
- Ответы Supabase разбираются так, чтобы в интерфейсе показывались `message`, `details` и `hint`.

## Как проверить

1. Выполните `npm ci`.
2. Запустите `npm run dev`.
3. Откройте «Склад» и добавьте модель.
4. После успешной записи появится зелёное сообщение, а модель отобразится ниже.

## Если появилась ошибка доступа Supabase

Проверьте в Supabase права `INSERT` и RLS-политики таблиц `products` и `batches`.
Текст ошибки теперь будет виден прямо в приложении и подскажет, чего именно не хватает.

Не отключайте RLS в рабочем приложении. Предпочтительный вариант — Supabase Auth и политики для роли `authenticated`. Текущий локальный пароль интерфейса не заменяет авторизацию Supabase.

## Сборка

Проект проверен командой:

```bash
npm run build
```
